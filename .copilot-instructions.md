# EXO — Instructions Copilot

## Source de vérité
`PROMPT_MAITRE.md` est le document unique. Toute question d'architecture → consulter ce fichier.

## Projet
EXO v5.2 — Assistant vocal IA offline-first (C++17 / Qt 6.9.3 / CMake / Windows).
Pipeline : capture micro → VAD → WakeWord → STT → NLU → Claude API → TTS → DSP → playback.

## Contrainte Anti-Piper
Ne JAMAIS proposer Piper TTS. Le TTS d'EXO est XTTS v2 (Coqui), fallback Qt TTS.

## Stack
- **C++17**, Qt 6.9.3, CMake, MSVC 2022
- **TTS** : XTTS v2 CUDA RTX 3070 (port 8767)
- **STT** : Whisper.cpp Vulkan AMD 6750 XT, modèle medium (port 8766 → whisper-server.exe :8769)
- **LLM** : Claude `claude-sonnet-4-20250514`, SSE, 8 FC tools
- **Audio** : RtAudio WASAPI (capture 16kHz), QAudioSink (playback 16kHz)
- **Python** : 3.11 (`.venv_stt_tts` — 6 services IA) / 3.13 (`.venv` — orchestrateur)
- **7 services** : exo_server :8765, stt :8766, tts :8767, vad :8768, wakeword :8770, memory :8771, nlu :8772
